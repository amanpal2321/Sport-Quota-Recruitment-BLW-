# Sport-Quota-Recruitment-BLW-

This project was developed as part of a BLW internship. It serves as a **sports recruitment system** for BLW, enabling new candidates to register for various games. The platform also includes an admin login panel, where admins can approve registration requests and candidates can check their application status.

## Features

- **Candidate registration** for sports/events
- **Admin login panel** for managing registration requests
- **Application status tracking** for candidates
- Dashboard for administrators to approve or reject registrations

## How It Works

1. **Candidate Registration:** New users can create an account and register for available sports quotas.
2. **Admin Approval:** Admins log in, view pending requests, and approve or reject applications.
3. **Status Check:** Candidates can log in and check the status of their application.
